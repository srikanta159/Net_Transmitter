# Security Policy

## Supported Versions

The following versions of Net_Transmitter are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Net_Transmitter, please do **NOT** open a public issue. Instead, report it privately by sending an email to:

**hello@srikantadas.com**

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept (PoC).
- Any proposed fix or remediation advice.

We will review reports within 48 hours and coordinate a coordinated disclosure and patch release.
